# 🖥️ Windows Task Manager (C++/Qt 6)

A lightweight Windows Task Manager application built with C++ and Qt6 (QtWidgets + QML).

## 🚀 Key Features
* 📊 **Real-time Resource Monitoring:** Live tracking of CPU and RAM usage percentages.
* 📈 **Smooth QML Pulse Charts:** Integrated QML/Qt Quick components for dynamic performance visualization.
* 📋 **Process Management:** Detailed listing of active processes and application tasks.
* ⚡ **Performance Optimized:** Low background resource consumption with a responsive UI.

## 🛠️ Tech Stack
* **Language:** C++17
* **Framework:** Qt 6 (Qt Widgets, Qt Quick / QML)
* **Build System / IDE:** Qt Creator / qmake / MSVC or MinGW
